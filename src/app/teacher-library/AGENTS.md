# Teacher library

- Read typed `Resource` metadata; do not discover the whole Firebase bucket.
- Search and filter metadata locally, including Vietnamese text without diacritics.
- Display at most 24 new cards per interaction. Images use generated thumbnails and native lazy loading.
- Original documents remain the download source. Preview catalogs load only when a teacher opens a preview.
- Remote-only teaching resources remain available through the textbook category links until their catalog is published.
